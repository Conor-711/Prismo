A

来源，不是背书

“官方”只说明谁发布。公司披露、管理层预期与作者推断分别显示，不生成“利好已证实”。

B

作者正文下方直接露出官方信息，放在更长的价格证据与历史表现之前。点击卡片进入完整页面，返回保留阅读位置。

C

可持续追踪

追踪的是这家公司的官方披露渠道，不是又关注了一名博主。默认进入每日摘要，即时通知由用户选择。

bSmart 的切入口

入口仍然是人和观点

用户先被 Smart Account 的判断吸引，再花十几秒了解其涉及的官方披露。官方信息补足判断背景，不替用户判定作者正确，也不参与 Smart 排名。

对象升级为“官方事件”

一份 IR 新闻稿及同一份新闻稿的 SEC 附件，属于同一事件的不同文件。多个作者可以引用同一事件，但保留各自的推断与发布时间。

追踪留在现有结构中

入口在观点详情；官方渠道归属于标的详情；已追踪渠道进入现有追踪和提醒设置。不增加独立新闻 Tab。

匹配边界

作者引用

原帖有可解析的官方链接，或清晰可定位的官方引文。仍需确认该段内容，而非只认域名。

相关官方资料

作者未给链接，系统按公司、事件、日期和具体事实匹配。明确标注系统关联，不声称作者看过。

未找到来源

不生成官方摘要；有明确事实声称但无法匹配时，显示“暂无可关联的官方披露”。纯技术观点不强行插入空模块。

时间与更正

早于观点的材料才可充当当时依据。晚发资料只能标为后续更新；旧财报不会因为被再次提及变成最新财报。

第一版怎么落地

  1. 10 个主要标的试点优先当前有高质量观点的公司，建立 IR、Newsroom 与 SEC 公司身份映射。人工审核首批关系。
  2. 先做直接引用，再做语义关联财报发布与重大合作两类。候选检索后校验实体、财季、数字、时间、原文段落；低置信不展示。
  3. 上线卡片、独立详情和追踪摘要每条绑定出处。重要披露先进入摘要；用户明确开启后才即时推送，并按事件去重。
  4. 验证价值，不考核新闻数量看官方卡片打开率、原文打开率、追踪转化、来源错误率和通知退订率。人工抽检优先避免误关联。

数据入口与限制

NVIDIA 已提供 官方 RSS 和 邮件提醒。美国申报资料可从 SEC 开发者资源获取，遵守其访问约束。可公开读取不等于获得全文再分发许可；MVP 使用客观转述、必要短摘录、原文链接，版权条款按来源审查。

原型不连接采集、推送或交易服务。正式实施先定义 OfficialEvent / OfficialDocument / OpinionSourceLink，再接入后端管线；不在 iOS 中搜索网页或判断官方身份。
