# The Smart Crowd

投资者发现的高表现力 HTML 评审版，不替换已实现的 SwiftUI 首页。

打开 `bsmart-discovery-expressive.html` 即可交互，无服务器、远程字体或图片依赖。

## 表现与交互

- 发现池：可点选头像群像与焦点人物，分组覆盖全部候选者。
- 人物卡：连续浏览当前赛道人物，进入档案读取代表判断与近期观点。
- 赛道：按既有作者领域筛选，同步到人物池和观点模式。
- 观点：真实摘要、日期、作者与原帖来源；方向筛选可与赛道叠加。
- 研究阵容：本地追踪名单，人物名片、阵容、观点卡均可复制文案及导出 1080 × 1440 PNG。
- 分享卡支持三种配色。每页阵容最多 6 人，超过后可翻页逐页导出；不限制追踪人数。
- 阵容按单人、2-3 人、4-6 人分别使用肖像、纵向名片、双列群像排版。
- 桌面显示 App 与分享工作台；移动端为单屏 App，分享在弹层中打开。

## 数据边界

只读复用 `../investor-discovery/data.js` 的 28 位 X 作者、25 张内嵌头像和 88 条观点，以及 `../investor-discovery-unified/evidence.js` 的代表判断快照。日期、Score、排名、原帖身份不改动；缺失头像使用首字母，不伪造真人。观点明确标为结构化摘要，不冒充逐字原文。代表判断的区间超额收益不是实际账户收益或积分式 Score。页面和导出均标注快照与历史表现边界。

追踪使用独立 `bsmart.prototype.expressive.following.v1` 浏览器存储；不读写生产数据库，不新增评分、不发送社交帖子、不接入实时行情。

## 构建

```sh
node docs/product/prototypes/investor-discovery-expressive/bundle.mjs
```

源文件：`index.html`、`styles.css`、`app.js`、`share.js`。`bundle.mjs` 内嵌 CSS、现有 Lucide、头像与数据，生成可直接分享的单文件。
