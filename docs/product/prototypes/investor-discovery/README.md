# Investor Discovery / 首页人物发现

2026-09-09。独立 HTML 设计评审，直接打开 `bsmart-investor-discovery.html` 即可，无需服务器，也不依赖同目录其他文件。`index.html` 为分文件开发入口。

- A：头像池 + 焦点人物，优先展示探索密度。
- B：逐人发现，每位投资者展示完整背景，支持左右切换和触摸横滑。
- C：按研究领域选人，支持目录搜索。
- D：先读真实观点，再认识来源作者。

可切换并排/单屏；追踪在四个方案之间共享，仅存本原型的 localStorage。下方市场/追踪/持仓范围可切换，持仓范围 NVDA/MU/MSTR 仅为评审假设。作者档案展示快照内的真实观点与证据链接。底部 App 导航是静态布局参照，不模拟未实现的页面。

`export-data.mjs` 从项目 fixtures 选取 X 平台 Top 25% 中前 28 位作者，摘录原始字段与最多五条观点，并固定 Lucide 0.468.0。`data.js` 是评审快照，不是生产数据源；不重新评分、不编造收益、不声称实时事件，分类直接使用已有 specialty。日期保留原值，Top 比例向上取整仅用于展示。头像来自对应公开平台；下载失败时显示首字。

头像共 25 张，其余显示首字；原站不可用时通过 images.weserv.nl 获取同一公开头像的缩略图。全部图片和 Lucide 已随原型内嵌，浏览不发送网络请求（主动点开证据链接除外）。

重新导出数据需联网：`node docs/product/prototypes/investor-discovery/export-data.mjs`；随后运行 `node docs/product/prototypes/investor-discovery/bundle.mjs` 生成独立文件。不修改 iOS 或 API。
