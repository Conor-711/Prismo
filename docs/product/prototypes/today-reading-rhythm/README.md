# Today Reading Rhythm

2026-09-08 的独立 HTML 评审原型，不修改 SwiftUI 或数据算法。

- 直接打开 `index.html`，无需构建或服务器。
- 默认并排展示三页，可切成单屏体验；手机宽度自动使用单屏。
- 保留顶部价格观点图与三标签导航；图表为明确标注的布局示意，不表示真实 OHLC。
- 持仓与追踪：按持仓标的组织紧凑列表，追踪动态使用轻量行。
- 市场情况：两张等高热门卡片上下排列，Alpha 改成无外框发现条目。
- 聪明动态：一次展示作者身份，下面串联该作者多标的观点，不再套大卡片。
- 支持标签点击、左右触屏滑动、键盘方向键、来源筛选、追踪切换、观点详情与返回、明暗主题。

复用 `../today-home-tabs/data.js` 的本地观点快照、项目 Asset Catalog 和平台图标。资金操作沿用上一原型的历史样本。持仓、追踪和分组仅用于布局比较，不是新的推荐结果。远端作者头像不可用时退回姓名首字；Lucide 使用固定版本 CDN。主导航仅为保持上下文的外观预览，不实现其他 App 功能。

预览中的追踪状态只保存在页面内存，不同步 App。摘要列表限制行数，点击可读取未截断摘要与原始来源链接。
