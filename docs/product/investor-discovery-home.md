# 首页投资者发现

更新：2026-09-09。融合评审方案已进入原生 SwiftUI，不新增 Web 业务界面。

## 产品结构

- 人物池：采用单条横向队列，不做环绕。中央大头像显示真实平台 Top 比例，两侧头像随距离逐渐缩小；每个头像下缘都有平台标识。
- 简介卡：保留名称、一个平台标识、周期和风格；不显示裸 Score 或重复平台名。约 94pt 内以两行展示标的 Logo + ticker、结算窗口/股价变化，以及最早加分观点的方向、日期和参考价。点击代表作可查看精确发表时间、参考价格日期、原帖和结算区间；没有代表作时显示真实领域/覆盖标的，不以未知收益填零。
- 发现区不再提供“看观点”，观点由下半屏既有场景承担。
- 赛道：按作者擅长领域筛选，不对观点重新标行业、不由所选股票推断作者能力。
- 人物档案：复用现有概览、历史表现与代表作；上一位 / 下一位只在进入时的候选范围内工作。
- 搜索目录：支持姓名、账号、赛道、风格和已覆盖标的检索，可叠加仅已追踪。进入档案保留搜索结果范围，返回保留原首页状态。
- 追踪：所有入口使用 AppModel 的现有追踪状态和设备持久化，不创建第二套收藏。

原首页下半屏的持仓与追踪、市场情况、聪明动态继续保留，原生滚动和吸顶容器不变。新用户无持仓也可发现投资者；添加持仓仍在下半屏。

## 数据边界

`TodayInvestorDiscovery` 只投影已发布排名：要求显式有效 `platformPercentile <= 0.25`、有效平台排名和有限 Score。未知百分位不能靠默认值进入池，不新增收益、准确率或置信度。按既有平台百分位、平台排名及稳定身份排序，展示平台名称，不宣称这是新算出的跨平台总榜。

人物身份由平台与作者 ID 组合，名称不参与身份合并。赛道来自 `SmartAccountProfile.specialty`，不维护另一份行业股票表。首组以当前数据中 `@aleabitoreddit` 的 X ID 为默认焦点，只在其符合现有资格及所选赛道时采用；前五位依次为 2 位有头像的合格 YouTube 作者、默认 X 作者、第 3 位 YouTube 作者、当前候选中排名最前的 Reddit 作者。首屏及开始向左滑动时即可看到三个平台；Reddit 没有头像 URL 时仍采用真实姓名占位，不编造头像。仅改变人物池的展示位置，不更改平台排名、目录排序、百分位或覆盖范围。不符合资格、数据缺失时自然回退，不强行捏造或纳入候选。

代表作规则为“累计加分最多的标的 + 该标的最早的有效加分观点”。标的排序不改；从完整已结算正贡献历史中选最早观点，不仅查询已导出的高分点。日期、方向、参考价与后续结算表现统一绑定同一条观点，不混用更晚观点的涨幅。`representativeWork` 轻量摘要随作者列表返回，首页及目录不再依赖逐人加载 K 线/全文；旧数据没有该可选字段时，焦点稳定 650ms 后才请求现有证据缓存。网络失败不永久缓存为空。

参考价是发帖前已经完成的最近日线收盘价，不是精确到发帖瞬间的逐笔价格。纽约时间 16:00 前不得采用当日收盘，缺失不倒填未来入场价；收益仍按这条观点原有结算窗口计算。表面显示“最早加分”，不宣称一生首次看多/看空。档案连续浏览使用候选快照，来源声明、原文与完整译文仍保留。

人物池原生左右滑动、居中吸附，每位作者只出现一次，默认焦点两侧优先展示 3 位 YouTube 作者和 1 位 Reddit 作者；Reddit 首位及剩余列表均将有头像者前置（包括已核实的内置头像映射），同组保留原顺序，无头像者保留在后，不改变评分、排名或候选资格。仅用户点击或横滑才切换，不再自动滚动；删除人数/进度及暂停/继续整行。中央作者变化不改变下半屏所选标签，垂直滑动仍交给既有首页滚动容器。

Reddit 平台标识由共享 `SmartPlatformMark` 读取内置 `PlatformReddit` 图片，保留橙色背景与白色 Snoo，不再使用 `r/` 文字占位。资源复用仓库已有 `web/public/platform/reddit.png`，位于 iOS Asset Catalog，不依赖运行时下载；其他使用该控件的简介和观点来源同步修正。

## 工程落点

- `Features/Today/TodayInvestorDiscovery.swift`：候选投影、候选会话边界。
- `TodayInvestorPool.swift`：首屏人物编排和已有百分位展示，不参与评分。
- `TodayInvestorDiscoveryHighlight.swift`：校验已有代表作身份/结算状态，取既有窗口和股价变化用于简介。
- `TodayInvestorDiscoveryWork.swift`：Logo/标的、最早加分日期与参考价，及可追溯的价格口径明细。
- `Core/Models/SmartAccountRepresentativeIntro.swift`：可选轻量摘要契约；管线 `domain/smart_voice/representative_intro.py` 负责历史选择与参考价投影，客户端不重算。
- `TodayInvestorDiscoveryModule.swift`：赛道/选人状态和 AppModel 连接。
- `TodayInvestorDiscoveryPeople.swift` / `TodayInvestorPoolPortrait.swift`：原生手动横滑、横向大小层次与平台标识，保留焦点档案和追踪。
- `TodayInvestorDiscoveryDirectory.swift` / `TodayInvestorProfileBrowser.swift`：搜索目录、候选范围内连续浏览，复用现有作者详情。
- `TodayView.swift`：移除首屏行情挂载，其他三个场景与底部主导航不变。

HTML 位于 `prototypes/investor-discovery-unified/`，仅保留评审快照，不作为原生运行时数据源。
