# 持仓相关动态

日期：2026-09-07。此模块补充现有首页，不重做首页或改变 Smart 评分。

## 产品定位

- **持仓相关**：我持有的股票，最近有哪些值得阅读的 Smart 动态。
- **热门标的**：市场上较热门的观点。
- **Alpha 标的**：较少被讨论的机会与观点。

持仓相关不要求用户追踪作者，不混入自选标的，也不取代“追踪动态”。
第一版的依据是用户已添加的外部／手动持仓；并非新增券商同步，更不把本地交易沙盒视为真实资金。

## 同类产品参考

- [Delta / My Delta Home](https://support.delta.app/en/articles/9233147-my-delta-home)：将与所持／关注资产相关的内容和市场发现分开，以有限预览和查看全部降低首页负担。
- [Seeking Alpha / Portfolio-related headlines](https://help.seekingalpha.com/how-to-view-portfolio-related-headlines-articles-on-mobile)：为投资组合提供直接的相关内容入口。
- [Quartr / Watchlists](https://quartr.com/features/watchlists)：通过用户指定的股票集合限定研究内容的范围。

采用“持仓限定内容 + 首页少量预览 + 完整内容页”的结构，不复制行情终端或新闻聚合的复杂度。

## 展示与交互

位于价格观点图之后、热门标的之前。首页最多三条纵向紧凑卡片，尽量覆盖不同持仓；更多内容进入独立页面。
每条为标的 Logo、代码、已知仓位占比；其后是最多三行观点摘要／操作；底部为头像、平台标识、名称、来源类别和真实时间。
不增加解释性副标题、认证标识或 N_eff 等计算字段。使用现有主题色，适配深浅主题及 Dynamic Type。

完整页可叠加标的和 Smart Account / Smart Money 筛选。点击观点进入原文证据页；点击资金动态进入该次操作详情，保留观察时间与名义仓位变化，并可继续查看账户／外部证据。
无持仓时模块仍在，提供添加持仓；近 30 天无内容时如实显示空状态，不以过期数据补位。

## 第一版排序规则

1. 仅匹配 `PortfolioPosition.isPosition` 的标准化代码，包括只有占比的持仓；不按多空方向筛掉风险信息。
2. 发布时间／观察时间必须在当前时刻之前的 30 天内，未来时间不参与。
3. 每个平台／作者／标的保留最新观点；每个资金账户／市场／标的保留最新操作，不把两个来源合成为一项“确认信号”。
4. 新鲜度依次为 24 小时内、3 天内、7 天内、30 天内；档内已知仓位越大越优先，再按时间倒序。使用已有 Smart 作者／账户池，不在客户端重新计算或对比两个体系的原始分数。
5. 仓位占比优先采用有效的用户填写值；否则仅在全部持仓估值完整时计算，分母包括没有相关动态的持仓。未知占比不显示，也不补零。
6. 该排序是阅读优先级，不是收益预测、买卖指令或作者实际持仓认证。成本数据不被用来编造个性化交易建议。

## 工程边界

- 推荐投影与过滤：`Features/Today/TodayHoldingsActivity.swift`。
- 首页、完整页和列表项：`TodayHoldingsActivityModule.swift`、`TodayHoldingsActivityRow.swift`。
- 资金操作详情：`Features/Smart/SmartMoneyMovementDetailView.swift`。
- 数据沿用 `AppModel` 与现有 API；无数据库、后端契约、评分算法或持仓持久化变更。
- 后续接通真实交易账户时，应通过统一的真实持仓 read model 接入，不直接读模拟账本。
