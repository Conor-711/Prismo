## 布局

顶部保持标题和设置入口，`TodayInvestorDiscoveryModule` 包含作者赛道筛选、头像池、搜索目录和统一人物档案。投资者发现区不再重复提供看观点入口。

首页标题仅保留“今日”和设置/帮助入口。发现区在紧凑屏幕显示两行头像，常规屏幕三行；所有候选都可分组浏览。三个场景标签在标准字号首屏露出，不被底部浮动导航遮挡；详情图尺寸不变。

首页用两级主模块区分人物与观点：上方为“发现聪明投资者 / Smart investors”，下方为“他们怎么看市场 / Their market views”。两者使用同级 20pt 标题，分别配人物、观点图标；模块间用细线和留白区分，不增加解释性小字。观点区主标题随发现头部滚出，之后仍只吸顶三个标签。

发现区下为左对齐、内容宽度的文字标签，选中项使用左对齐荧绿色下划线。标签 16pt，持仓相关、追踪动态、热门标的、Alpha 和聪明动态等内部模块标题统一为 15pt；层级随 Dynamic Type 保留。英文市场标签缩写为 Market，无障碍名称保留 Market overview。长标签允许换行，不再把字号压到子标题以下。

| 子页 | 现有模块 |
| --- | --- |
| 持仓与追踪（默认） | 持仓相关、用户追踪账户的动态 |
| 市场情况 | 热门标的两张、轻量 Alpha 条目两条及完整列表入口 |
| 聪明动态 | 按投资者聚合的 Smart Account / Smart Money 动态 |

不修改底部主导航。无持仓时仍可进入市场和聪明动态；持仓与追踪保留添加入口、推荐追踪与空状态。

## 交互与边界

- 使用 SwiftUI 原生分页；三个子页可点击标签或在内容区域横滑。
- 只有一个共享发现区实例，切页不重置模式、赛道与人物选择。
- 发现区可随上滑离开屏幕，文字标签随后吸顶。
- 每个子页独立垂直滚动；进入未阅读子页时延续头部收起状态，返回已阅读子页时恢复其位置。
- 发现区的纵向拖动衔接当前滚动页；赛道横滑与人物点按由发现区处理。下拉刷新仍使用既有 AppModel 方法。
- 取消标签页内的横向轮播：热门保留上下两张，阿尔法和追踪动态改为纵向排列。穿插简介轮播不再额外插入三条信息流。
- 卡片仍进入既有详情，热门与阿尔法保留共享元素转场。
- 滚动内容底部预留浮动导航空间，末尾卡片可完整滚入阅读区域。
- 不重算 Score、不修改推荐和聚合算法、窗口、原始观点、接口或数据库。

## 内容差异化（已实施）

三个场景不应仅替换标题或背景色，应采用不同的阅读组织方式；统一字体、图标、方向色和详情操作。

- **持仓与追踪：紧凑清单。** 持仓动态以标的为视觉锚点，每条观点使用适配深浅主题的独立底色、细边框和间距，标的组本身不套外框；追踪动态以账户为锚点。保留已有持仓占比等真实上下文。
- **市场情况：标的卡片。** 保留热门标的的多人头像和单条重点摘要，卡片使用浅绿/浅蓝色底与深色文字；Alpha 使用更轻的发现条目，显示首条来源摘要、对应作者/钱包身份、排名和时间，不将聚合最高排名错误归给当前来源。保留现有热门两张上下排列，避免再嵌横向轮播。
- **聪明动态：作者时间线。** 每位作者只出现一次身份信息，下方纵向排列最新观点/操作；去掉包裹整组作者的大卡片边框，用留白与时间分组。这里的时间是事件数据，不是功能说明小字。

实现沿用已有来源、Score、推荐选取和数据窗口，不引入 HTML 样例仓位或行情。持仓清单按选中来源筛选后沿用原本最多 3 条的分散标的预览，随后按标的首现顺序展示，标的/仓位头只出现一次；组内保留原排序。追踪动态的 Smart Money 行直接打开该笔操作证据，不再按标的回退匹配其他钱包。长摘要在列表限制行数，详情不截断；不增加解释性小字。

热门卡片在相同字号下保持等高，摘要字号与卡片高度共同响应 Dynamic Type。持仓和 Alpha 的头像单独进入账户主页，其余摘要区域进入对应证据或 Alpha 详情，避免作者入口抢占整行点击。首页持仓与追踪的模块容器不重复使用懒加载，内部长列表仍保留按需渲染；追踪模块使用独立无障碍容器，保留每一行的访问标识。
