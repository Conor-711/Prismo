# 新版 Onboarding：发现 → 追踪 → 交易

日期：2026-09-16。状态：三页原生 iOS 引导已实现；HTML 保留为交互基准。
首次资料页精简继续作为登录后的前置步骤，随后进入本引导。

交互演示：[打开单文件 HTML](prototypes/onboarding-three-step/bsmart-onboarding.html)。支持三页切换、追踪、原文、订单预览、可选头像/用户名资料页与明暗模式；没有真实交易或账号请求。

## 一条连续的故事

新用户需要明白：这里帮我找到哪些值得关注的人，如何持续看到他们的判断，以及怎样把自己认可的判断变成交易。

三页尽量使用同一位真实作者和同一标的，延续头像、价格图和观点。每页一个主视觉、一个主要操作。不要把它设计成模块名称目录，不以开户、入金或真实下单作为完成条件。

## 第 1 页：发现聪明的投资者

- 标题：**投资，该追踪谁？**
- 主视觉：复用现有 X 真实头像池，明确展示 1,283 位已观察投资者，再聚焦从中筛选出的 Serenity（`@aleabitoreddit`）及其 AAOI 代表作。
- 作者行：头像、姓名、平台、Top 百分比。
- 图表：最早至多三个看多节点、首次日期与价格、后续区间最高价及最高涨幅。点击节点可看原观点。
- 正文示例：**作者在 $53.69 看多 AAOI，之后在 $95.34 再次看多，后来最高到 $128.96。** 数值来自打包的审定价格记录，不将股价涨幅表述为作者收益。
- 排名解释：**Top 15%：在 X 参与排名的投资者中，排在前 15%。** 它不是胜率，也不是收益率。
- 用三个简短阶段呈现来源：**公开观点 → 后续表现 → 排名**；不展开公式。
- 主按钮：**看看他的新观点**。

抓取人数与正式排名分母分开。示例可以是正向历史案例，但不将历史高点涨幅称为作者实盘收益或可复制收益，也不暗示能事前选中最高点。保留必要口径：历史表现不代表未来结果。

## 第 2 页：跟踪他们的新观点

- 标题：**他有新判断，你能跟上。**
- 主视觉：沿用 Serenity，展示 2026-08-24 的 AAOI 观点，包含方向、需求判断和融资稀释风险；历史记录按原时间展示，不假装刚刚发布。
- 交互：用户点击 **追踪**，按钮变为 **已追踪**，同一条观点进入“我的追踪”的视觉区域。选择立即写入已有追踪状态。
- 首屏以一位作者为焦点；用户可展开选择更多作者，但不要求每个平台都选、不预先替用户关注。
- 聪明共识/热门标的和阿尔法以此观点旁的小型实际关联入口呈现，而非再占两张教学卡：前者看其他高排名作者的判断，后者看较少来源覆盖的新判断。没有实际关联时不硬拼示例。
- 主按钮：**看看如何交易**；追踪不是进入下一步的强制条件。

“时刻跟踪”是用户价值，不是当前采集与推送的 SLA。展示数据最近更新时间。只有数据发布通知真正配置、验收后，才在主动追踪后提供“开启更新通知 / 稍后”；用户选择开启再弹系统授权。不把每天约两次发布说成作者发帖即时逐条推送。

## 第 3 页：交易你认可的观点

- 标题：**认可这个判断？直接交易。**
- 主视觉：上方保留该作者和观点，下方衔接现有交易面板，清楚对应同一标的。
- 交互：可点交易入口，查看金额输入、仓位方向和订单确认信息。教学预览不调用订单执行、不签名、不创建钱包、不提交资金操作。
- 一条清晰顺序：**看判断 → 选金额 → 自己确认**。强调用户选择，不默认复制作者交易，不预选高杠杆。
- 必须清楚区分股票观点与实际交易工具；如果交易的是永续合约，预览和正式交易都保留合约类型、杠杆、费用、强平风险等必要信息，不伪装成买入现货股票。
- 不可交易标的显示查看观点，不映射到同名但错误的合约；案例优先选已有准确合约映射的标的。
- 主按钮：**进入 bSmart**。真实交易在进入 App 后主动发起，沿用原账户、余额、风险与滑动确认流程。

## 页面节奏

- 顶部品牌和“跳过”；底部三枚进度点与主按钮。三页任意一步跳过都能进首页。
- 每页一张主视觉，不做卡片套卡片；标题适中，使用正文讲一个具体例子，而不是增加解释性小字。
- 头像/标的/观点跨页共享元素转场；只做一次短引导动画，不自动翻页，不自动轮播。Reduce Motion 下淡入或直接切换。
- 明暗模式复用 App token；小屏、大字号允许内容滚动，底部按钮避让键盘与内容。
- 本地打包审定案例与头像，不让开屏等待网络。数据标明原日期；更新失败不冒充实时。
- 首次资料设置完成后进入引导；引导完成与绑定券商、钱包准备、入金、追踪数量解耦。已完成老引导的用户不强制重看，可从设置查看新版说明。
- 成功标准：用户能说明为什么看这个人，能主动追踪并打开其观点，知道在哪里交易。不以强迫首单衡量教学完成。

## 首次资料页（本轮实现）

- 只保留一个必填字段：**用户名**。维持原有 3–24 位字母/数字/下划线、以字母开头规则及服务端唯一性检查。
- 头像缩为横向紧凑选择行，标明“可选”；无需添加照片即可继续，不再显示占据大块空间的头像和菜单。
- 首次没有昵称/简介输入；提交时以规范化用户名作为初始昵称、简介留空，不把提供方真实姓名默认公开。
- 后续个人页的编辑入口保留昵称、简介和头像修改。
- 同一云端资料接口、版本冲突与账号隔离不变；只有服务端成功保存才通过资料关卡。用户名占用或保存失败保留输入并就地提示。
