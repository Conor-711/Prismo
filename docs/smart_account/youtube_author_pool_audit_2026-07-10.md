# YouTube Score 作者池审计（2026-07-10）

## 目的

在正式计算 YouTube 作者 Score 前，先验证候选作者规模、频道公开画像分布，以及项目内已有投资判断证据是否足够。

本报告只描述采集结果和门槛敏感性，不修改 `YOUTUBE_ALGORITHM.md` 中的正式规则。

## 数据口径

- 频道发现样本：`yt_platform_channel`，来自 37 组财经、股票、交易、标的和多地区查询。
- 频道实时画像：2026-07-10 通过 YouTube Data API `channels.list` 刷新。
- 一年内容证据：`yt_video.published_utc >= now - 365 days`。
- 已分析标的：频道在 `yt_analysis` 中覆盖的去重 ticker 数。
- 已结构化判断：频道在 `yt_judgment` 中覆盖的去重 ticker 数。
- 可执行 call：`sv_call.source = 'youtube' AND is_actionable_call = 1`。
- 正式 Score 默认资格：`n_eff >= 4 AND settled_calls >= 5`。

## 回填前的 Score 证据缺口

| 指标 | 结果 |
|---|---:|
| 已生成 YouTube `sv_call` | 810 |
| 至少有一个 call 的作者 | 227 |
| 当前 `sv_investor_score` 作者 | 191 |
| 满足 `n_eff >= 4` 且 `settled_calls >= 5` | 27 |

因此需要区分两个目标：

1. 候选作者池达到 300 人以上：当前数据已经满足。
2. 至少 300 人拥有可信 Score：当前远未满足，需要按作者回填一年上传历史并增加可结算 call。

## 建议的第一版池子方案

建议先构建 500 人左右的候选池，为媒体剔除、失效账号和证据不足预留缓冲：

```text
硬条件：
  公开且稳定的 channel_id
  subscriber_count >= 1,000
  一年内至少命中 1 条美股股票或 ETF 相关视频

排序条件：
  一年内相关视频数
  已覆盖 ticker 数
  可提取投资判断的视频比例
  粉丝数（log capped，只用于 discovery）

分池：
  个人投资者/分析师
  媒体/机构
```

不建议把“至少判断 2 个 ticker”设为当前硬门槛，因为项目现有 ticker 搜索只覆盖 44 个标的，会把采集偏差误当成作者能力不足。

## 下一步数据工程

1. 对候选频道读取 uploads playlist，而不是继续逐 ticker 搜索。
2. 回填候选作者最近一年的全部上传视频元数据。
3. 过滤出美股股票和 ETF 相关内容，并支持一条视频映射多个 ticker。
4. 对相关视频执行分析、call 提取、价格结算和 Score 评分。
5. 在个人作者池和媒体池内分别检查至少 300 人的覆盖与资格情况。

uploads playlist 的配额成本远低于为每位作者重复调用 `search.list`，也能减少热门 ticker 和搜索排序造成的样本偏差。

## 第一版生产运行结果

上述方案已在同日完成第一轮生产运行，作者池版本为 `youtube-sv-pool-v1-20260710`。

当前置信度分布为：`medium=2`、`low=202`、`observing=223`。首轮尚无 high 作者，原因是 high 门槛需要 `n_eff >= 60` 且至少 80 个已结算 call；这应通过后续自然增量积累，而不是降低门槛。

两个回填失败频道没有 uploads playlist；另有少量频道虽在池内但没有足够可结算的方向性观点。正式合格作者达到 336，已超过“至少 300 人”的首版置信度目标。

质量审计后，映射规则升级为 `youtube-title-v3`：简介普通公司名不参与映射，`NEXT`、`GOLD`、`HBM` 等歧义 token 必须由 cashtag 或公司名确认；`SMR`、`NET`、`APP` 等只有在显式 `SMR stock` 语境下才接受裸 ticker。结算层还会将“the next Nvidia”“missed Palantir”“bigger than GameStop”等比较参照归零，避免把被比较公司误记为作者推荐。
