# MU / NVDA / AAPL / SPCX / PLTR 标的级 SV 集体行为回测

生成日期：2026-07-19

## 1. 研究问题与口径

研究高 `SV_Platform` 作者在热门标的上形成集体看多/看空后，是否对后续收益具有预测价值。

- 来源范围为全部正式平台作者池；各平台按观点日当时的平台排名独立取 Top/Bottom 10%。
- 作者排名只使用当时已经退出并结算的历史 Call，不使用未来结果或当前榜单回填。
- 主口径固定为 7 个自然日信号窗、下一交易日开盘入场、20 个交易日收盘退出。
- 加权净强度要求至少 2 条同向 Call 和 2 位独立 Top 作者；作者净人数按每位作者最新 Call 一人一票。
- 连续同向交易日合并为一个事件；另计算同标的持仓未退出前不重复入场的保守结果。
- 本报告是指定热门标的的事后历史切片，不是独立样本外投资业绩。

## 4. 标的判断

### MU：20D 有明显正向迹象，但属于高波动小样本

- 5D 加权净强度平均收益约为 0，作者净人数平均超额仅 +1.19%；优势主要在 20D 展开。
- 20D 两项指标平均超额均超过 +11%，中位超额也为正，不完全由单一赢家造成。
- 但样本几乎全部为看多，且 MU 本身处于高波动行情，PF 会被少数大涨事件放大。

### SPCX：数据不足

没有正式作者 Call 和事件，且价格历史不足20个交易日。当前不能评价集体行为预测效果，应先补 ticker 元数据、精确候选映射、作者观点打标和更长价格历史。

## 5. 总结

| 标的 | 当前判断 |
|---|---|
| MU | 20D 正向迹象最强，但高波动、小样本、偏多，需要新增数据验证 |
| AAPL | 结果相对一致，但全是看多事件，存在市场阶段偏差 |
| NVDA | 接近中性，作者净人数略有正向迹象，加权和分歧无效 |
| PLTR | 普通集体看多显著失效，可能存在拥挤/追涨效应，值得研究分歧或反向过滤 |
| SPCX | 无正式 Call，无法回测 |

本次结果不支持一个统一门槛覆盖所有热门标的。标的自身的波动结构、作者覆盖和拥挤程度会显著改变同一 SV 指标的效果。
